PYTHON FISHING

A simple fishing game in the python console.<br>
'stable' folder contains the exe file from the latest build, which is all you need in order to run it.<br>

Controls:<br>

w/a/s/d for movement on the main map<br>
space to drop the line when fishing and interact with map<br>
e to sell in shop<br>
number and enter to buy from shop<br>
i to view inventory
